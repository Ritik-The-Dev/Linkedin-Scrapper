Backend

LinkedIn Lead Extractor API

This deployment serves the REST API only. There is no UI here — point the frontend at this origin.

  • GET /health
  • POST /api/leads
  • GET /api/leads
  • GET /api/leads/search?q=
  • GET /api/leads/stats
  • GET /api/leads/:username
  • POST /api/leads/:username/refresh
  • POST /api/leads/import
  • DELETE /api/leads/:username
Start with /health to confirm the function is live.
